# zoli-token
A commemorative token celebrating Zoli, a very good ginger cat, built as a playful little project for cat lovers.


## Trust & transparency

ZOLI is currently a Solana Devnet project.

- Official mint: `7Jg5G78983maURLsyD7sDr226Rdmwv24wBKH2nGZNfzQ`
- Current supply: 1,000,000,000 ZOLI
- Decimals: 6
- Mint authority: active during development
- Public fundraising: not active
- No guaranteed value or return
- Security rule: never share a seed phrase or private key

See `transparency.html`, `security.html`, `terms.html` and `privacy.html` for the public-facing trust layer.
