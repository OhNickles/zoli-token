DATA // MINIMAL BY DESIGN

PRIVACY.

The current static Devnet website is intentionally simple and does not require an account.

CURRENT SITE

The project does not currently run its own user account database, payment system or newsletter. The site does not ask for seed phrases or private keys.

WALLETS

When wallet connectivity is added, a public wallet address may be read so the site can show on-chain information such as a ZOLI balance. Public blockchain activity is inherently visible on-chain.

THIRD PARTIES

The site is hosted through GitHub Pages and links to services such as GitHub and Solana Explorer. Those services may process information under their own privacy practices.

FUTURE CHANGES

If analytics, forms, accounts or other data collection are added, this page should be updated before those features are used publicly.
